# P8 故障验证、真实模型评估与受控发布

> 状态：planned。依赖 P0-P7；这是发布门，不是继续添加功能的任务卡。

## 目标

按真实生产函数/装配链路完成工程验收、故障注入、真实模型行为评估、备份/回退演练和受控灰度，明确所有 PASS、FAIL、NOT_RUN、BLOCKED。

## 必须执行

- 运行规划中的全量测试矩阵，覆盖 Registry、生命周期、终止、Notebook、检索、反思、UI、认证和迁移。
- 注入关停/重启、网络失败、取消、并发更新、旧 embedding 响应、observer 重投、unknown 外发等故障。
- 只模拟外部 LLM/OneBot/embedding 边界；集成测试必须进入真实 composition root、Registry、SQLite、Sender/Outbox。
- 使用固定脱敏聊天样本，在旧版/桥接版/新策略/selfEvolution 版本间比较；单独报告 mock 控制流与真实模型行为。
- 保存 `docs/verification/<revision>/` 下的环境、命令退出码、测试结果、脱敏 transcript/effect trace、持久化/UI 检查、模型行为、限制和回滚演练。
- 按发布顺序：插件桥接与沉默（selfEvolution 关闭）→ 测试环境 Notebook → review 反思 → 有限群灰度；生产启用需管理员明确批准。

## 非目标与硬约束

- 不因缺凭据、测试未启动或外部服务不可用猜测为通过。
- 不用沉默比例、笔记数量、反思次数作为成长指标；不自动把历史一次性灌入生产。
- 不以 `git checkout` 代替 SQLite/WAL 一致性备份和数据回退方案。

## 允许的自主决策

可选择故障注入工具、样本数量、报告格式和灰度观测窗口；不得降低验收矩阵、跳过 unknown 外发保护或绕过管理员批准。

## 验收

- 工程验收全部 PASS，或逐项记录明确 blocker、影响和回退方案。
- 真实模型效果单独有证据；mock 不能替代真实行为结论。
- 发布前完成备份与恢复演练；未知外发不自动重试，迁移失败安全停用插件并保留数据。
- 生产启用条件、负责人、回退版本和停止信号明确写入发布记录。

## 完成回报

给出最终 DoD 对照表、未执行项、已知限制、灰度结果和可执行回退命令；未获得管理员批准时只交付测试环境结果。
